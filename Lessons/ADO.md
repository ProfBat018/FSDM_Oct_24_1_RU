# Тема урока: ADO.NET

Для того чтобы работать с базой данных в C#, есть уже встроенный ODBC(Open Database Connectivity) метод, который помогает нам делать запросы в БД и назыается он Microsoft.Data.SqlClient. `ADO.NET` - это набор классов, который осуществляет данный механизм. Для начала нам нужно понять что для работы с БД есть два способа подключения.

1. Connected
2. Disconnected

При подключенном режиме абсолютно все действия происходят в режиме онлайн. С помощью класса SqlConnection мы сперва настраиваем подключение, а затем вызываем нужные нам методы. Для запросов существует 3 метода:

1. ExecuteNonQuery
2. ExecuteReader
3. ExecuteScalat

`ExecuteNonQuery`- это запросы, которые не возвращают данные.

`ExecuteReader` - это все **select** запросы

`ExecuteScalar`- это все запросы, которые выполняются агрегирующими функциями.

При отключенном режиме вы используете класс `SqlDataAdapter`, который делает запрос в БД и заполняет нужный вам `DataSet`.

`DataSet` - это класс, который состоит из ваших таблиц и все будущие действия проходят уже с ним. То есть получается, что вы сперва один раз скачиваете нужные вам таблицы в оперативную память, а уже потом работаете с ним так, как вам удобно.

Преимущество такого подключения - это скорость считывания данных, так как вам не приходится делать запрос в БД. Из минусов стоит отметить то, что запись данных очень медленная и вы можете уже работать над неактуальными данными.
