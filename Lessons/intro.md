# Тема урока
- Введение в ADO.NET и EF.CORE

мы уже с вами прошли основы программирования и понимаю из чего состоит фундамент приложений. С помощью ООП и паттернов мы приблизительно понимаю архитектуру приложений. На этом предмете мы будем строить Data слой приложений, то есть заниматься описанием и конфигурацией бихнес-модели и связывать ее с БД. 


Для того чтоьы ваше приложение на C# было связано с БД, вам необходимо настроить ее подключение к ней. Тут у нас всего один выбор. Для работы C# и MSSQL Server нам необходим ODBC Driver(Open database connectivity driver), который является мостом между нами и SQL сервером. Все комманды, запущенные со стороны .NET, переходят на SQL. 

Для работы этого драйвера нам нужно установить пакет `Microsoft.Data.SqlClient`. Вы должны понимать что это основной пакет, который нужен для работы с БД. 

На данном предмете мы будем использовать три подхода работы с БД => ADO.NET, EF.CORE, Dapper. 


# ADO.NET 

Данный подход, подразумевает запуск sql скриптов напрямую с C# на SQL Server, с помощью SQL комманд. Он тяжелее для написания, но работает быстрее чем EF.CORE

# EF.CORE 

Данный способ под капотом использует ADO.NET для работы с БД, но его встроенные механизымы позволяют мне работать с таблицами как с C# свойствами, то есть делать `Mapping` - привязку C# объектов к SQL. EF.Core является framework-ом и ORM(Object relational mapping) системой. 

# Dapper 

`Dapper` - это `MicroORM`, который тоже связывает сущности к БД, но мы уже для работы также должны писать SQL скрипты для подключения к БД. 


Так как ADO.NET является базой, мы для начала начнем с него.
