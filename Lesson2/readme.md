# Встроенные БД 
- master
- msdb
- model
- tempdb 

После установки MS SQL SERVER у вас на ПК запускается Server для 
работы с БД. В последствии логично предположить что данные самого сервера тоже должны где-то хранится.
Для этого существует БД, который называется `master`.

`msdb` - это БД, которая используется для хранения информации о заданиях, 
выполняющиеся в SQL Server Agent. Sql Server Agent - это служба, которая будет автоматически запускать 
`maintenance plans`, `jobs`, `alerts` и т.д.

`model` - это шаблонная БД, которая используется при создании новых БД. При создании новой БД
все объекты, которые есть в `model` будут скопированы в новую БД.

`tempdb` - это временная БД, которая используется для хранения временных объектов, 
таких как временные таблицы, переменные таблиц и т.д.

# Indexes

Если бы мы просто хранили данные в таблицах, то работа с ними была бы очень медленной. Для того чтобы 
ускорить процесс считывания данных из таблиц, используются индексы. Индекс - это структура данных,
которая позволяет быстро находить строки в таблице по определенному столбцу. 

Существует два типа иендексов:
- Кластерный индекс (Clustered Index) - это индекс, который определяет физический порядок строк в таблице. 
  В таблице может быть только один кластерный индекс, так как строки могут быть упорядочены только по одному столбцу.
- Некластерный индекс (Non-Clustered Index) - это индекс, который не определяет физический порядок строк в таблице. 
  В таблице может быть несколько некластерных индексов, так как строки могут быть упорядочены по нескольким столбцам.
