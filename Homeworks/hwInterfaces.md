# 🧪 Домашнее задание: Прогноз Погоды через Интерфейсы (C# + OpenWeatherMap)

## 🎯 Цель

Научиться использовать **интерфейсы** в C#, абстрагировать логику работы с внешними API и структурировать проект по принципам чистой архитектуры.

---

## 📌 Задача

Создайте консольное приложение на C#, которое позволяет пользователю ввести название города и получить текущую погоду в этом городе. Данные нужно получать с помощью **официального API OpenWeatherMap**.

---

## 📚 Что должно быть реализовано

- **Интерфейс**, описывающий поведение сервиса получения погоды.
- **Реализация этого интерфейса**, взаимодействующая с API OpenWeatherMap.
- Логика обработки ответа от сервера и отображения результата в человекочитаемом виде.
- Минимальная обработка ошибок (например, при вводе неверного города или потере соединения).
- Конфигурация API-ключа без его захардкоживания в коде.

---

## ⚙️ Технические детали

- Используйте `HttpClient` для запросов.
- Ответ API необходимо парсить из JSON.
- Температуру показывайте в **градусах Цельсия**.
- В ответе должно отображаться:
  - Название города
  - Описание погоды (например, "ясно", "облачно")
  - Температура

---

## 🧠 Дополнительное задание (по желанию)

Реализуйте вторую версию сервиса, которая возвращает **фиктивные данные** без подключения к интернету (например, `MockWeatherService`). Это поможет при тестировании.
