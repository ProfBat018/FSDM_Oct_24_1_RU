# 🛰 Задание: Система оповещений через делегаты

## 📘 Описание

Ваша задача — реализовать консольное приложение, моделирующее работу системы датчиков и оповещений. Приложение должно использовать **делегаты** для подписки различных обработчиков на изменение состояния объекта.

## 📋 Условия задачи

Представьте, что у вас есть некий **датчик**, который отслеживает значение (например, температуру, уровень влажности или произвольное числовое значение).

Каждый раз, когда значение датчика изменяется, должны **вызваться все подписанные обработчики**, реализованные с помощью делегатов.

## 🎯 Основные требования

- Приложение должно позволять:

  - Устанавливать новое значение датчика
  - Добавлять новых подписчиков на изменение значения
  - Удалять подписчиков
  - Выводить список текущих подписчиков

- Подписчики должны реализовывать различные действия, например:
  - Логирование изменений
  - Вывод предупреждений при определённых условиях
  - Выполнение различных реакций

## 🛠 Ограничения

- Использовать только **делегаты** (не `event`, не `IObservable`)
- Все действия должны происходить через **консольный интерфейс**
- Архитектура должна позволять легко добавлять новых подписчиков

## 📌 Пример взаимодействия с пользователем

```text
Введите новое значение датчика: 78
[ЛОГ]: Значение изменилось на 78
[ОПОВЕЩЕНИЕ]: Внимание! Высокое значение: 78

Введите команду:
1. Добавить подписчика
2. Удалить подписчика
3. Установить новое значение
4. Показать список подписчиков
5. Выход
```
