# Тема урока: События в C# 

На прошлых уроках мы проходили с вами делегаты, которые являются указателем на метод. События в C# - это механизм связанный с делегатами, который позволяет запускать методы при возникновении определенных событий. События позволяют объектам сообщать другим объектам о том, что произошло какое-то событие.

## Что такое события ?

`Event` - это объект, который подписывается на определенный делегат и позволяет вызывать методы, которые были подписаны на это событие. События используются для уведомления других объектов о том, что произошло какое-то событие.

## Как создать событие ?

Чтобы создать событие, нужно определить делегат, который будет использоваться для подписки на событие. Затем нужно определить событие, которое будет использовать этот делегат. Пример будет в проекте Lesson8.
