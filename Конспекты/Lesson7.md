## Records 

`Записи` (records) в C# - это новый тип ссылочного типа данных, который был введен в C# 9.0. Они предназначены для упрощения создания неизменяемых объектов с семантикой сравнения по значению.

По началу студентам бывает сложно разобраться с ними, потому что они выглядят как нечто между классами и структурами, но имеют свои особенности. Давайте разберем что такое записи, как их использовать и какие преимущества они предоставляют.

### Что такое записи ?
Записи - это ссылочные типы, которые автоматически предоставляют реализацию методов `Equals`, `GetHashCode` и `ToString`, что делает их удобными для работы с **неизменяемыми** данными. Они позволяют легко создавать объекты, которые сравниваются по значению, а не по ссылке.

### Как использовать записи ?

Записи используются для работы с `Data Transfer Objects (DTO)`, для работы с данными из БД(Базы Данных) и в других случаях, когда нужно создать неизменяемый объект. Также у них есть преимущество сравнения по значению, что дает нам возможность легко сравнивать объекты и использовать их в коллекциях, таких как `HashSet` или `Dictionary`.

### Пример использования записей

У `redord`-ов есть разные способ декларивания: 

1. С помощью фигурных скобок

```csharp

public record Person 
{
    string Name;
    int Age;
}

```
2. С помощью `record`-синтаксиса

```csharp
public record Person(string Name, int Age);
```
3. С помощью `record`-синтаксиса с инициализацией свойств

```csharp
public record Person
{
    public string Name { get; init; }
    public int Age { get; init; }
}
```
4. С помощью `record`-синтаксиса с инициализацией свойств и конструктором

```csharp
public record Person(string Name, int Age)
{
    public string Name { get; init; } = Name;
    public int Age { get; init; } = Age;
}
```

### Преимущества использования записей
- **Неизменяемость**: Записи по умолчанию являются неизменяемыми, что делает их безопасными для многопоточного программирования. Здесь большиество студентов неправильно понимают, что записи неизменяемы, но это не значит, что они не могут иметь изменяемые свойства. Они просто не могут быть изменены после создания. Вот пример:

```csharp
public record Person(string Name, int Age)
{
    public string Name { get; init; } = Name;
    public int Age { get; init; } = Age;
}
```
а если сделать его mutable, то он будет выглядеть так:

```csharp
public record Person(string Name, int Age)
{
    public string Name { get; set; } = Name;
    public int Age { get; set; } = Age;
}
```

- **Сравнение по значению**: Записи автоматически предоставляют реализацию методов `Equals` и `GetHashCode`, что позволяет сравнивать их по значению, а не по ссылке.
- **Удобство работы с данными**: Записи позволяют легко создавать объекты, которые представляют собой данные, и автоматически генерируют методы для работы с ними.


## Реальные примеры использования записей 

Записси часто используются в следующих сценариях:
1. **DTO (Data Transfer Objects)**: Записи идеально подходят для передачи данных между слоями приложения, так как они обеспечивают неизменяемость и сравнение по значению.
2. **Работа с данными из БД**: Записи могут использоваться для представления данных, полученных из базы данных, так как они позволяют легко сравнивать и передавать данные.
3. **Конфигурационные объекты**: Записи могут использоваться для хранения конфигурационных данных, так как они обеспечивают неизменяемость и удобство работы с данными. Конфигурационные объекты - это объекты, которые содержат настройки приложения, такие как параметры подключения к базе данных, настройки кэша и т.д. Они часто используются для хранения настроек, которые не должны изменяться во время работы приложения.


# Способы взаимодействия с файловой системой 

Для работы с файловой системой в C# есть несколько классов и методов. 

1. **Класс `File`**: Этот класс предоставляет статические методы для работы с файлами, такие как создание, удаление, копирование и перемещение файлов. Например:
2. **Класс `Directory`**: Этот класс предоставляет статические методы для работы с директориями, такие как создание, удаление, копирование и перемещение директорий. 
3. **Класс `Path`**: Этот класс предоставляет методы для работы с путями к файлам и директориям, такие как получение имени файла, расширения файла и т.д.
4. **Класс `FileInfo`**: Этот класс предоставляет методы и свойства для работы с файлами, такие как получение информации о файле, изменение атрибутов файла и т.д. Он позволяет работать с файлами более гибко, чем класс `File`.
5. **Класс `DirectoryInfo`**: Этот класс предоставляет методы и свойства для работы с директориями, такие как получение информации о директории, изменение атрибутов директории и т.д. Он позволяет работать с директориями более гибко, чем класс `Directory`.
6. **Класс `FileStream`**: Этот класс позволяет работать с файлами на более низком уровне, предоставляя возможность чтения и записи данных в файл. Он позволяет работать с файлами как с потоками данных, что дает больше контроля над процессом чтения и записи.
7. **Класс `StreamReader` и `StreamWriter`**: Эти классы позволяют читать и записывать текстовые данные в файлы. Они обеспечивают удобный способ работы с текстовыми файлами, позволяя читать и записывать строки текста.
