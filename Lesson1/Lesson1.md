## Что такое база данных и типы баз данных

`База данных` - это представление данных в формате для хранения. 

Существует разные типы баз данных: 
1. Реляционные 
2. Нереляционные 

Первый тип мы еще успеем с вами обсудить, давайте пока поговорим о нереляционных БД. 

До сегодняшнего дня вы уже использовали разные файловые форматы для хранения информации, такие как `.txt`, `.bin`, `.json`, `.xml`. Данные файловые базы данных помогали хранить нужную вам информацию в разном виде. 

Но что делать, если нам нужно хранить родственные отношения между данными ?
Например, если у нас есть таблица с пользователями и таблица с заказами, то как нам связать эти две таблицы ?

Давайте представим, как это будет выглядеть в виде `json`: 

```json
{
  "users": [
    {
      "id": 1,
      "name": "Alice",
      "orders": [
        {"order_id": 101, "amount": 250},
        {"order_id": 102, "amount": 150}
      ]
    },
    {
      "id": 2,
      "name": "Bob",
      "orders": [
        {"order_id": 103, "amount": 300}
      ]
    }
  ]
}
```

В этом примере я нарушаю принцип хранения нормальных данных, так как я храню информацию о заказах внутри информации о пользователях.

Для того чтобы хранить нормальные данные, появились реляционные базы данных, 
которые позволяют хранить данные в виде таблиц и связывать их между собой с помощью ключей.

На этом моменте я сразу дам спойлер или сделаю отступление к тому, что уже существуют 
нереляционные базы данных, которые позволяют хранить данные в виде документов, графов и других форматов. Например, 
- **MongoDB** - это нереляционная база данных, которая позволяет хранить данные в виде документов
- **Neo4j** - это графовая база данных, которая позволяет хранить данные в виде графов.
- **Redis** - это база данных, которая позволяет хранить данные в виде ключ-значение. Его мы в будущем будем использовать 
для Server Side Caching.

## История SQL
SQL или же Structured Query Language - это язык запросов к реляционным базам данных. Первая версия SQL 
была разработана в 1970-х годах в IBM. Тогда еще она называлась SEQUEL (Structured English Query Language). Так как компания 
IBM не смогла зарегистрировать торговую марку SEQUEL, то название было изменено на SQL. Open Source версия SQL
появилась в 1990-х годах, и с тех пор SQL стал стандартом для работы с реляционными базами данных. Компания Microsoft 
в 1989 году выпустила свою версию SQL под названием T-SQL (Transact-SQL),
которая стала стандартом для работы с реляционными базами данных в Microsoft SQL Server.

Так как SQL является стандартом ANSI (American National Standards Institute), то он поддерживается 
многими реляционными базами данных, такими как MsSQL, MySQL, PostgreSQL, Oracle, SQLite и другими. Между ними конечно же
есть небольшие отличия, но в целом если вы знаете один из них, то на изучение других уйдет максимум 1-2 дня.

# Глоссарий 
- **База данных** - это организованная коллекция данных, которая позволяет эффективно хранить, управлять и извлекать информацию.
- **Реляционная база данных** - это тип базы данных, в которой данные хранятся в виде таблиц, связанных между собой с помощью ключей.
- **SQL** - это язык запросов, используемый для взаимодействия с реляционными базами данных.
- **MS SQL** - это СУБД(Система Управления Базами Данных) от компании Microsoft,
которая использует SQL для работы с реляционными базами данных. Можно сказать что это как .NET для C#.
- **SSMS** - это Microsoft SQL Server Management Studio, графическая оболочка для работы с MS SQL. Скажем IDE для работы с MS SQL.

## Из чего состоит БД 

База данных состоит из двух файлов: 
1. *.mdf* - Main Data File - основной файл базы данных, в котором хранятся данные.
2. *.ldf* - Log Data File - файл журнала транзакций, в котором хранятся все изменения, внесенные в базу данных.

ВЫ должны понимать, что все созданное человеком создается для упрощения нашей жизни. Самый простой способ представления 
реляционной базы данных - это таблицы. 
Соответственно, в реляционной базе данных мы будем работать с таблицами, которые состоят из строк и столбцов.

## Понятие DDL, DML, DCL, TCL
- **DDL (Data Definition Language)** - это язык определения данных, который используется для создания,
изменения и удаления объектов базы данных, таких как таблицы, индексы и представления. 
Примеры команд DDL: `CREATE`, `ALTER`, `DROP`.
- **DML (Data Manipulation Language)** - это язык манипуляции данными, который используется для работы с данными в таблицах.
Примеры команд DML: `SELECT`, `INSERT`, `UPDATE`, `DELETE`.
- **DCL (Data Control Language)** - это язык управления данными, который используется для управления доступом к данным в базе данных.
Примеры команд DCL: `GRANT`, `REVOKE`, `Deny`.
- **TCL (Transaction Control Language)** - это язык управления транзакциями, который используется для управления транзакциями в базе данных.
Примеры команд TCL: `COMMIT`, `ROLLBACK`

# Таблица работы оператора LIKE

| Текст    | Шаблон   | Описание шаблона                       | Совпадение (TRUE/FALSE)                         |
|----------|----------|---------------------------------------|------------------------------------------------|
| Apple    | A%       | Начинается с `A`, затем любые символы | TRUE                                           |
| apple    | A%       | Начинается с `A` (регистр важен/не важен) | **FALSE** (case-sensitive) / TRUE (case-insensitive) |
| Apple    | %le      | Заканчивается на `le`                   | TRUE                                           |
| Apple    | %p%e     | Содержит `p` где-то, затем где-то `e`  | TRUE                                           |
| Apple    | _pp%     | Любой символ + `pp` + любые символы    | TRUE                                           |
| Apple    | [A-C]%   | Начинается с буквы от `A` до `C`       | TRUE                                           |
| Banana   | [A-C]%   | Начинается с `A-C`                      | FALSE                                          |
| Car      | [A-C]%   | Начинается с буквы от `A` до `C`       | TRUE                                           |
| Apple    | A___e    | `A`, потом ровно 3 любых символа, затем `e` | TRUE                                    |
| Apple    | A__e     | `A`, потом ровно 2 любых символа, затем `e` | FALSE                                   |

## Объяснения символов шаблона в `LIKE`

| Символ   | Значение                                |
|----------|----------------------------------------|
| `%`      | Любое количество символов (в том числе 0) |
| `_`      | Один любой символ                       |
| `[abc]`  | Один символ из списка (a, b или c)     |
| `[a-c]`  | Один символ из диапазона a до c        |
| `[^abc]` | Один символ, **не входящий** в список  |
