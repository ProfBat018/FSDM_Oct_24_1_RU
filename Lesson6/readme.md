# String functions 
Для работы со строками в SQL есть множество функций.
Вот некоторые из них:
- `UPPER(string)` - преобразует строку в верхний регистр.
- `LOWER(string)` - преобразует строку в нижний регистр.
- `TRIM(string)` - удаляет пробелы в начале и конце строки.
- `SUBSTRING(string, start, length)` - извлекает подстроку из строки, начиная с позиции `start` и длиной `length`.
- `CONCAT(string1, string2, ...)` - объединяет несколько строк в одну.
- `REPLACE(string, old, new)` - заменяет все вхождения `old` в строке на `new`.
- `LENGTH(string)` - возвращает длину строки.
- `POSITION(substring IN string)` - возвращает позицию первого вхождения `substring` в строке `string`.
- `LEFT(string, length)` - возвращает первые `length` символов из строки.
- `RIGHT(string, length)` - возвращает последние `length` символов из строки.

Вот пример использования некоторых из этих функций:

```sql
SELECT 
    UPPER('hello world') AS upper_case,
    LOWER('HELLO WORLD') AS lower_case,
    TRIM('   hello world   ') AS trimmed_string,
    SUBSTRING('hello world', 1, 5) AS substring,
    CONCAT('hello', ' ', 'world') AS concatenated_string,
    REPLACE('hello world', 'world', 'SQL') AS replaced_string,
    LEN('hello world') AS string_length,
    LEFT('hello world', 5) AS left_part,
    CHARINDEX('hello world', 'world') AS position,
    RIGHT('hello world', 5) AS right_part;
```

# Date functions
Для работы с датами в SQL также есть множество функций. Вот некоторые из них:
- `CURRENT_DATE` - возвращает текущую дату.
- `CURRENT_TIME` - возвращает текущее время.
- `CURRENT_TIMESTAMP` - возвращает текущую дату и время.
- `DATEADD(interval, number, date)` - добавляет указанное количество интервалов к дате.
- `DATEDIFF(interval, date1, date2)` - возвращает разницу между двумя датами в указанных интервалах.
- `FORMAT(date, format)` - форматирует дату в соответствии с указанным форматом.
- `DATEPART(interval, date)` - возвращает часть даты (год, месяц, день и т.д.) в указанном интервале.
- `DATENAME(interval, date)` - возвращает имя части даты (например, название месяца) в указанном интервале.
- `GETDATE()` - возвращает текущую дату и время.
- `Year(date)` - возвращает год из даты.
- `Month(date)` - возвращает месяц из даты.
- `Day(date)` - возвращает день из даты.
- `DATEFROMPARTS(year, month, day)` - создает дату из указанных года, месяца и дня.

Вот пример использования некоторых из этих функций:

```sql
SELECT 
    DATEADD(DAY, 5, '2023-10-01') AS date_after_5_days,
    DATEDIFF(DAY, '2023-10-01', '2023-10-10') AS days_difference,
    FORMAT('2023-10-01', 'yyyy-MM-dd') AS formatted_date,
    DATEPART(YEAR, '2023-10-01') AS year_part,
    DATENAME(MONTH, '2023-10-01') AS month_name,
    GETDATE() AS current_datetime,
    YEAR('2023-10-01') AS year_from_date,
    MONTH('2023-10-01') AS month_from_date,
    DAY('2023-10-01') AS day_from_date,
    DATEFROMPARTS(2023, 10, 1) AS constructed_date;
```

# Numeric functions
Для работы с числовыми данными в SQL также есть множество функций. Вот некоторые из них:
- `ABS(number)` - возвращает абсолютное значение числа.
- `ROUND(number, decimals)` - округляет число до указанного количества десятичных знаков.
- `CEILING(number)` - округляет число до ближайшего большего целого.
- `FLOOR(number)` - округляет число до ближайшего меньшего целого.
- `POWER(number, exponent)` - возводит число в указанную степень.
- `SQRT(number)` - возвращает квадратный корень числа.
- `RAND()` - возвращает случайное число от 0 до 1.
- `SIGN(number)` - возвращает знак числа (-1 для отрицательных, 0 для нуля, 1 для положительных).
- `LOG(number)` - возвращает натуральный логарифм числа.
- `EXP(number)` - возвращает e в степени числа.
- `PI()` - возвращает значение числа π (пи).
- `GREATEST(value1, value2, ...)` - возвращает наибольшее значение из списка.
- `LEAST(value1, value2, ...)` - возвращает наименьшее значение из списка.


# Conditional operators
В SQL есть несколько условных операторов, которые позволяют выполнять различные действия в зависимости от условий. Вот некоторые из них:
- `CASE` - позволяет выполнять условные выражения. 
- `IF` - позволяет выполнять условные операции, но поддерживается не во всех СУБД.
- `COALESCE` - возвращает первое ненулевое значение из списка.
- `NULLIF` - возвращает NULL, если два значения равны, иначе возвращает первое значение.
- `IIF` - это сокращенная форма оператора `CASE`, которая позволяет выполнять простые условные проверки (поддерживается в некоторых СУБД, например, в SQL Server).
- `EXISTS` - проверяет, существует ли хотя бы одна строка, удовлетворяющая условию.
- `IN` - проверяет, содержится ли значение в списке или подзапросе.
- `BETWEEN` - проверяет, находится ли значение в заданном диапазоне.

# Transactions 

Транзакции - это фишка в SQL, которая позволяет сгруппировав несколько операций 
обеспечить их безопасное выполнение. Транзакции подчиняются требованиям `ACID`:
- **Atomicity (Атомарность)** - все операции в транзакции выполняются как единое целое. Если одна из операций не удалась, то все изменения откатываются.
- **Consistency (Согласованность)** - транзакция переводит базу данных из одного согласованного состояния в другое. Все ограничения и правила целостности должны соблюдаться.
- **Isolation (Изолированность)** - транзакции выполняются независимо друг от друга. Изменения, сделанные в одной транзакции, не видны другим транзакциям до тех пор, пока транзакция не будет зафиксирована.
- **Durability (Надежность)** - после фиксации транзакции изменения сохраняются в базе данных, даже в случае сбоя системы.
