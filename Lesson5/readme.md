## Подзапросы

Подзапросы - это запросы, которые выполняются внутри других запросов. Они позволяют использовать результаты одного запроса в другом запросе. Подзапросы могут быть использованы в различных частях SQL-запроса, таких как SELECT, FROM, WHERE и HAVING.

## Advanced data types in SQL

В `SQL` данные делятся на несколько категорий:

- scalar
- column
- row
- table

Скалярные значения - это все значения, к которым вы привыкли: числа, строки, даты и т.д. То есть обычные литералы, с которыми мы работали до сегодняшнего дня.

Колонка - это набор скалярных значений, которые имеют одинаковый тип данных. Например, столбец в таблице - это колонка, которая содержит значения одного типа данных.

Строка - это последовательность колонок, с разными данными, но строго определенного порядка и типа.

Таблица - это набор колонок.

Таблицы также могут быть временными, то есть их можно создавать и удалять во время выполнения программы. Временные таблицы могут быть полезны для хранения промежуточных результатов. 

```sql 
CREATE  TABLE #temp_table (
    id INT,
    name VARCHAR(50)
);
``` 

Временные таблицы существуют только в течение текущей сессии и автоматически удаляются после ее завершения. 

## Views(представления) 

Представления - это виртуальные таблицы, которые создаются на основе других таблиц. Они позволяют упростить работу с данными, скрывая сложные запросы и предоставляя удобный интерфейс для доступа к данным. Представления могут использоваться для фильтрации, агрегации и объединения данных из нескольких таблиц. 

Представления создаются с помощью оператора `CREATE VIEW`. Они могут быть использованы в запросах так же, как и обычные таблицы. 

```sql
CREATE VIEW view_name AS
SELECT column1, column2
FROM table_name
WHERE condition;
```

Давайте сразу рассмотрим разницу между представлением и временной таблицей. 
Представление - это виртуальная таблица, которая не хранит данные, а только определяет запрос, который будет выполнен при обращении к ней. Временная таблица - это реальная таблица, которая хранит данные в течение текущей сессии. 

Представления могут быть использованы для упрощения запросов, скрытия сложных операций и обеспечения безопасности данных. Они позволяют создавать абстракции над данными, что делает работу с ними более удобной и понятной.

В дальнейшем для выполнения представлений мы будем использовать `WITH` конструкцию, которая позволяет создавать временные представления, которые будут доступны только в рамках текущего запроса. 

```sql 
WITH view_name AS (
    SELECT column1, column2
    FROM table_name
    WHERE condition
)

SELECT *
FROM view_name;
```
